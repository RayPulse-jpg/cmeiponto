# Caveman Compress

Read the input `.md` file and rewrite its content in `caveman` (ultra-compressed) mode.
Remove all fluff, articles, pleasantries, and unnecessary explanations.
Keep all technical commands, code blocks, and facts intact.
Output the compressed file ready to replace the original.
